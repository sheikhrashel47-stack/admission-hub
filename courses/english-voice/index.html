🧱 Prerequisites (পূর্ব-প্রয়োজনীয়)

Voice শেখার আগে নিচের বিষয়গুলো স্পষ্ট থাকা দরকার। না থাকলে শুধুমাত্র প্রয়োজনীয় অংশটুকু এখানে দেওয়া হলো।

1. Subject, Object, Verb চেনা

Active বাক্যে সাধারণত Subject কাজটি করে, Object কাজটি গ্রহণ করে।

Rahim writes a letter. → Rahim = Subject, writes = Verb, a letter = Object।

Passive-এ Object (a letter) → নতুন Subject হয়ে যায়।

2. Tense চেনা (Simple, Continuous, Perfect, Perfect Continuous)

প্রতিটি Tense-এর নিজস্ব structure আছে। Passive-এর সূত্র বুঝতে হলে Tense চেনা জরুরি।

Present Simple: write / writes → Passive: am/is/are written
Past Simple: wrote → Passive: was/were written
3. Verb Forms (V₁, V₂, V₃, V₄) ও Voice-এর মূল সূত্র

Passive-এ সবসময় V₃ (Past Participle) বসে। Verb-এর Transitive হওয়া আবশ্যক (অর্থাৎ Object থাকতে হবে)।

write — wrote — written (V₃) → Passive: is written

এই অধ্যায়ের সাথে সম্পর্কিত গুরুত্বপূর্ণ পরিভাষা।

🎯 Exam Strategy & Checklist

  1. প্রশ্ন পড়ে আগে ঠিক করুন — Active নাকি Passive চাওয়া হচ্ছে।
  2. Subject → Object চিনুন। যদি Object খুঁজে না পান, Verb intransitive হতে পারে।
  3. Tense চিনুন, তারপর be + V₃ বসান।
  4. Interrogative হলে helping verb-এর পরে Subject রাখুন।
  5. Negative-এ not helping verb-এর পরে।
  6. Modal passive: modal + be + V₃।
  7. "by + agent" প্রায়ই ঐচ্ছিক — বাদ দিলেও গ্রামারিকভাবে সঠিক।
  8. সন্দেহ হলে Rule Card ও Contrast Lab-এর শর্টকাট দেখুন।
