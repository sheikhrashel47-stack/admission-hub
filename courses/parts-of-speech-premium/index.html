10-second Decision Tree

  1. Target word tense/action নিচ্ছে? → verb test করো।
  2. Target-এর পরে noun আছে? → determiner / adjective / noun modifier / preposition ভাবো।
  3. Target-এর পরে clause আছে? → conjunction ভাবো।
  4. Target কি noun replace করছে? → pronoun।
  5. Target কি relation + object দেখাচ্ছে? → preposition।
  6. Target কি reaction? → interjection।
