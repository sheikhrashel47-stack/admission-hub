## Slide plan

প্রতিটি core lesson-এ 5–6টি slide থাকবে: hero/concept, formula বা rule, data visual/table, example/compare, trap, quick practice। Lessons 14–16-এ summary assets ভেঙে 6–8টি readable slide করা হবে। মোট target প্রায় 80 slides। Dense 12-tense table, exception table, trap database, micro-rules, এবং answer key horizontal overflow ছাড়া responsive scroll/table card হিসেবে render হবে।

## Source fidelity rules

Source MCQ-এর English wording, options, answer এবং grammar meaning বজায় থাকবে। PDF OCR-এ ভাঙা বাংলা explanation clean করে সহজ বাংলায় লেখা হবে। Source MCQ-তে কোনও ambiguity থাকলে original answer key এবং rule context মিলিয়ে verify করা হবে। New practice MCQ source question-এর duplicate হবে না; প্রতিটি নতুন MCQ নির্দিষ্ট lesson/topic/difficulty-তে tag করা থাকবে।

## Visual system

Voice-specific visual branch-এ এই visual types থাকবে: `voice-split`, `voice-formula`, `voice-flow`, `voice-tense-grid`, `voice-pronoun-map`, `voice-double-object`, `voice-question-map`, `voice-group-verb`, `voice-reporting`, `voice-object-detector`, `voice-state-action`, `voice-preposition-map`, `voice-advanced-pipeline`, `voice-trap-board`, `voice-micro-rules`, `voice-master-map`, এবং `voice-score-rubric`। এগুলো semantic educational visuals হবে; decoration-only animation নয়। Motion subtle এবং reduced-motion safe থাকবে।

## Result and progress design

Lesson/topic tags ব্যবহার করে result sheet-এ Basic, Intermediate, Admission, Trap/Advanced এবং specific topics (Tense, Modal, Imperative, WH, Group Verb, Reporting, No-Passive, Fixed Preposition, Advanced Structure) অনুযায়ী performance দেখানো হবে। Source/practice breakdown, score band, weak topics, retry, bookmark, and resume position থাকবে।
