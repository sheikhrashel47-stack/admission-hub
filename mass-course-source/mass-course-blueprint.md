## MCQ composition

The pack contains source-aligned questions extracted where the source format allowed reliable answer parsing, plus clearly tagged source-supplement questions where a guide’s answer key or layout required normalization, and a separate practice bank for every course. Every question has four options, a bounded correct-answer index, a topic tag, and an explanation field for the existing Exam Zone and Result Sheet.

## Visual system

Each lesson has a six-slide learning sequence: Core Rule / Formula, Rule Matrix, Solve Flow, Correct-versus-Trap contrast, Admission Trap Board, and Quick Recall. The shared renderer applies course-specific color themes while preserving the existing mobile-first card, navigation, progress, exam, bookmark, note, edit, duplicate, delete, and result interactions.

## Safety and maintainability

All ten course IDs are unique and coexist with the seven existing courses. The raw PDF/HTML extraction files are working artifacts only; the repository deliverable keeps the compact course data, blueprint, QA record, and automated validators rather than the original extracted source dump.
